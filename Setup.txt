System Dependencies
--------------------
Before installing Python packages, you need to install the following system-level dependencies on Windows:

1. Poppler
    - Required by pdf2image to convert PDFs to images.
    - **Download**: Get the latest release from Poppler for Windows.
    - **Installation**: Extract the archive and add the bin directory (e.g., `poppler-24.08.0\Library\bin`) to your system PATH environment variable.
    - **How to Add to PATH**:
      - Right-click 'This PC' > Properties > Advanced system settings > Environment Variables.
      - Under 'System variables', find 'Path', click 'Edit', and add the bin directory path.
      - Click OK to save.

2. Tesseract-OCR
    - Required by pytesseract for optical character recognition (OCR).
    - **Download**: Install from Tesseract-OCR for Windows.
    - **Installation**: Run the installer and add the installation directory (e.g., `C:\Program Files\Tesseract-OCR`) to your system PATH (follow the same steps as above).

Setup Instructions
-------------------
Follow these steps to set up your project from scratch on Windows:

1. **Install Python**
    - Download and install Python 3.8 or higher from python.org.
    - During installation, check "Add Python to PATH" to make it accessible from the command line.
    - Verify installation: Open Command Prompt (cmd) and run `python --version`.

2. **Set Up System Dependencies**
    - Install Poppler and Tesseract-OCR as described in the "System Dependencies" section above.
    - **Verify Poppler**: Run `pdftoppm -v` in cmd (should display version info).
    - **Verify Tesseract**: Run `tesseract --version` in cmd.

3. **Create a Project Directory**
    - Open Command Prompt and create a directory for your project:
      ```
      mkdir my_project
      cd my_project
      ```

4. **Create a Virtual Environment**
    - Run the following to create and activate a virtual environment:
      ```
      python -m venv venv
      venv\Scripts\activate
      ```
    - After activation, your prompt should show `(venv)`.

5. **Save the requirements.txt File**
    - Open a text editor (e.g., Notepad), paste the `requirements.txt` content from above, and save it as `requirements.txt` in your project directory.

6. **Install Required Packages**
    - With the virtual environment activated, run:
      ```
      pip install -r requirements.txt
      ```

7. **Set Up Environment Variables**
    - Create a file named `.env` in your project directory with your OpenAI API key:
      ```
      OPENAI_API_KEY=your_api_key_here
      ```
    - Replace `your_api_key_here` with your actual OpenAI API key (sign up at openai.com if needed).

8. **Copy Your Code**
    - Save your `main_28.py` file in the project directory.

9. **Run the Application**
    - Start the FastAPI app with:
      ```
      uvicorn main_28:app --host 127.0.0.1 --port 8000
      ```
    - Open a browser and go to `http://127.0.0.1:8000` to test it.
